Honest Crossover

For strictly append-only, single-pass, in-order aggregation with zero retractions, zero late arrivals, zero range queries, and zero branching, a plain sequential loop wins on initial ingest. On MomentsMonoid, bulk tree build (10.2 ms @ 100k, 47.9 ms @ 500k) breaks even against a single-pass -O3 Rust loop after 31–34 late edits or range queries.
