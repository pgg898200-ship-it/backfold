Patchfleet uses the code already in Git to shrink what agents send each other. It restored 1,380 held-out coding-agent patches byte for byte. Its migration compiler also keeps exact edits current as repositories change.

Archive coding-agent patches

Keep the exact patch from every attempt. Send the archive to a reader with the pinned Git repositories and restore the patch files in submission order. The kit includes the CLI and a pack-and-restore example. Requires Python 3.10+, Git and zstd.
