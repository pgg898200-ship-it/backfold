How to read the result · The built-in examples use synthetic events. Wire size includes the four-byte stream header and every record header. Patch records copy a shared prefix and suffix from the previous frame. A two-splice record can also reuse an unchanged middle span. An exact repeat takes one byte. Transport headers are outside this comparison.

    

      
Try it on your gateway

      
The CLI compares your capture with persistent gzip and WebSocket DEFLATE. The results depend on how often adjacent events share an envelope.

      
python -m pip install 'git+https://github.com/pgg898200-ship-it/backfold.git@eventfold-v0.1#subdirectory=companions/eventfold'
python -m eventfold compare < capture.sse
